# 📊 Decode Labs Data Analytics Internship

This repository contains the projects I completed during my **Data Analytics internship at Decode Labs**. The three projects cover the core data analytics workflow: cleaning raw data, exploring it to find patterns, and querying it with SQL.

## Projects

| # | Project | Folder | Focus |
|---|---------|--------|-------|
| 1 | Data Cleaning | [`project1_datacleaning`](./project1_datacleaning) | Turning raw, messy data into an analysis-ready dataset |
| 2 | Exploratory Data Analysis (EDA) | [`project2_EDA_project`](./project2_EDA_project) | Finding patterns, trends and outliers with statistics and visualizations |
| 3 | SQL Analysis | [`project3_Sql_analysis`](./project3_Sql_analysis) | Answering business questions by querying data with SQL |
