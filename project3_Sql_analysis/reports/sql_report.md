# SQL Analysis Report

## Project Overview
Analyzed an e-commerce dataset using SQLite and SQL queries.

## Queries Performed
- Total orders count
- Average order value
- Highest and lowest order values
- Product-wise order analysis
- Payment method analysis
- Order status analysis
- Referral source revenue analysis

## Key Findings
- Dataset successfully imported into SQLite.
- SQL aggregations were used to generate business insights.
- Product and revenue trends can be identified using GROUP BY queries.

## Conclusion
SQL was used to extract, summarize, and analyze structured data efficiently.
